# ROADMAP Sequenced so each phase leaves the site in a shippable state. --- ## Phase 1 — Pitch build ✅ complete Get something real in front of Almed before the meeting. Four pages, bilingual, brand-accurate, built from their own documents. - [x] Design system from the brand book - [x] Home, Menu, Locations, Franchise - [x] EN/AR with true RTL - [x] Branch register digitised - [x] Drawer nav + floating order/chat actions ## Phase 2 — Presentable Everything needed before this is shown to the client. - [ ] Deploy to Vercel, shareable preview URL - [ ] **Native Gulf Arabic review of every string** — blocking - [ ] Careers page (simple, indexable — QSR hiring is continuous) - [ ] Contact page with routed enquiry form - [ ] Confirm WhatsApp number, wire the Chat action - [ ] Replace placeholder Silicon Central data - [ ] Favicon and social share image - [ ] Lighthouse pass: performance, a11y, best practices, SEO ## Phase 3 — Production-ready - [ ] JSON-LD: `Restaurant` per branch, `Organization` + `subOrganization`, `BreadcrumbList`, `FAQPage` - [ ] `sitemap.xml`, `robots.txt`, canonicals, `hreflang` for en/ar - [ ] GA4 + Meta Pixel via GTM, Consent Mode v2 - [ ] UAE PDPL cookie consent banner - [ ] Per-branch Google Business Profile alignment, NAP consistency - [ ] Food photography integrated — the design is currently image-free - [ ] Licensed DIN Condensed Bold + Aftika webfonts, self-hosted - [ ] Cross-browser and cross-device QA, both directions - [ ] FAQ page — captures long-tail "near me / halal / opening hours" search ## Phase 4 — CMS binding The data layer already exists. This phase points it at a CMS instead of static JSON. - [ ] Choose CMS (recommendation: Sanity — best non-technical editor experience) - [ ] Model: pages, menu categories, menu items, branches, enquiries - [ ] Bilingual fields with Arabic as a first-class locale, not a translation - [ ] Replace `fetch('assets/data/*.json')` with the CMS endpoint - [ ] Role-based access for Almed's marketing team - [ ] CMS training session + written documentation + screen recordings ## Phase 5 — Post-launch - [ ] Offers / Promotions page — QSR repeat visits are deal-driven, and it gives the future promotions feature somewhere to live without a rebuild - [ ] Per-branch pages where menus or hours differ - [ ] Franchise section extensible into a standalone microsite - [ ] App-shell / PWA groundwork for the eventual native app --- ## Deliberately out of scope Named here so nobody rebuilds them by accident. - **Native online ordering.** Almed is outsourcing order management. The site links out. - **Payment gateway.** No transactions on this site. That is Juan Valdez's brief. - **Prices.** They live on ChatFood. - **Real-time reservations.** Not a JJ Chicken requirement. - **Commercial data.** No fees, royalties or unit economics on the public site.
